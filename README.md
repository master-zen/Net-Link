# Net-Link

Network rule lists, Surge modules, runtime scripts, icons and tracker subscriptions. Existing subscription URLs remain stable.

- [Surge modules](Surge/Module/): application and startup ad filtering.
- [Surge rules](Surge/Rules/): domain, IP and tracker lists.
- [Surge icons](Surge/Icon.json): icon index.
- [Surge scripts](Surge/Scripts/): client runtime assets.
- [Clash rules](Clash/Rules/): compatible rule payloads.
- [Trackers](Trackers/Trackers.txt): merged tracker URLs.

The main branch contains only distributed assets and user-facing documentation. Build inputs, validation and publishing infrastructure are maintained separately. Client-side runtime scripts must remain downloadable. Third-party notices accompany the applicable artifacts.
