# SuperAdBlock

Status: review-only; no public module or raw source mirror is published until redistribution rights are verified.

428 active sources are listed in `data/sources/SuperAdBlock_URLs.txt`. The daily workflow runs at 21:43 UTC (05:43 Beijing time), downloads each source into an isolated runner workspace, records SHA-256 and verifies run identity, builds offline, performs deterministic validation and reports counts and per-source section coverage. The review artifact contains hashes and counts only, not upstream content or generated rules. All sources are attempted independently; a failed source stops the formal build after an isolated review build and complete failure inventory. The download manifest is uploaded even on failure. Source text is never executed or written to public artifacts while publication is disabled.

Conservative scope: domain and suffix blocks with ad-specific evidence, exact-host ad URL rejects, and a small set of equivalent static local responses. Unknown or broad regex, ambiguous domains, global settings, logical/IP rules, external redirects, unreviewed executable resources and arbitrary body manipulation are excluded. Existing critical allowlist and Moyu functional API protections apply. Beta and stable KeLee sources count as one family. Newly added Amlabort, Maasea and the existing Net-Link startup module are treated as unverified lineage and cannot satisfy independent suffix corroboration. Regex alternatives, wildcards and ambiguous path expressions are excluded except for the existing explicit Douban exceptions; literal ad path prefixes are bounded. Map Local options are matched independently of their order. Spotify and YouTube binary-response scripts require a different verified profile; their in-stream ad removal is not guaranteed. Conflicting actions are excluded; exact and suffix domain redundancy is removed. This is not a complete semantic translator, antivirus or substitute for Surge and app testing.

The upstream QingRex README defers redistribution rights to original authors; KeLee ProxyResource uses CC BY-NC-SA 4.0, AWAvenue uses GPL-3.0 and blackmatrix7 uses GPL-2.0. Publicly combining potentially protected material under these different terms requires source-specific permission and a compatible combined-license review, including attribution, applicable notices and source distribution. Do not enable the publication gate without documenting evidence for every URL and the combined license review in `data/sources/SuperAdBlock_publication.json`. The gate is an administrative attestation, not legal advice or an automated license determination.

When approved, the workflow stages tracked upstream snapshots, manifests and the final module at `Surge/Module/SuperAdBlock.sgmodule`, then publishes via the existing non-force publisher. Until then, no public module URL is active.

Upstream references: [QingRex](https://github.com/QingRex/LoonKissSurge), [KeLee](https://github.com/luestr/ProxyResource), [AWAvenue](https://github.com/TG-Twilight/AWAvenue-Ads-Rule), [blackmatrix7](https://github.com/blackmatrix7/ios_rule_script).

The daily workflow additionally discovers third-party JavaScript from downloaded modules, downloads it as inert data, hashes and deduplicates it, refreshes ClamAV definitions, scans signatures and parses Acorn AST without executing upstream code. Only scripts passing the narrow text-response transformation profile and endpoint/conflict tests can enter the generated module, with immutable-by-convention hash-named runtime files and per-script redistribution evidence. Unknown or failed scans do not qualify. A clean signature scan is not proof of safety. The script audit runs on successfully fetched modules even when other module sources fail. The seven extra platform sources are fmz200 (Facebook, Twitter network rules, X web response script, Spotify, YouTube) and app2smile (Spotify, YouTube); shared upstream lineage is not independent corroboration.

A failed antivirus setup or scan blocks generation when JavaScript references are present. The X web module is a distinct mechanism, not an independent author or a verified native-app ad blocker.

Audit hardening: URL canonicalization rejects query credentials and traversal; non-transient HTTP failures are recorded without retries; manifest counts must agree with individual source status. HTTP/HTTPS and nested URL scope collisions with different actions are rejected. Douban exemptions are bounded to the documented ad paths. Non-reject upstream domain policies are treated as protection, and protected wildcard descendants cannot be swallowed by a suffix rule. Map Local JSON MIME variants are normalized. Script scan reports include per-module references and unique content counts. Public executable approval requires the exact script SHA-256 in addition to source-specific permission. The publish job verifies staged archive identity, source hashes, module/report hashes, runtime script hashes and approval before invoking the non-force publisher. It does not claim on-device Surge validation or permission to republish. The pinned runner OS reduces environment drift.

The generator additionally accepts only static, bounded JSON response deletion (`del` or literal `delpaths`) of explicit ad fields under permitted containers. It regenerates its own jq expression rather than executing arbitrary upstream jq, preserves the original on errors, checks protected hosts and overlapping actions across URL, body and script sections, and guards the generated line for modern unified Surge cores (>=6008000). No upstream arbitrary jq or JS is executed in CI. The JavaScript auto-eligibility profile now requires the exact structural parse/delete-ad-fields/stringify pattern; arbitrary writes or deleting business fields cannot pass. Complex Protobuf/JavaScript remains in the scan report and requires additional verified transformations. This is not proof of live-app correctness.
